# My First C# Project

A simple console application built to explore the basics of the **C# programming language** and the **.NET SDK**. 
This project serves as my introduction to object-oriented programming, syntax rules and compiling C# code.

## 🚀 Features
* **Hello World Output:** Prints messages directly to the terminal.
* **Clean Code Structure:** Uses modern .NET structures.
* **Input handling:** Interacts with user commands via the console.

## 🛠️ Requirements & Setup

To run this project locally, you need to install the [.NET SDK](https://microsoft.com "dotnet SDK download").

1. **Clone or download** this folder to your machine.
2. Open your terminal or command prompt and **navigate to this directory**:
   ```bash
   cd path/to/your/first-csharp-folder
   ```

## 💻 How to Run the App

You can execute this project directly from the command line using the .NET CLI:

1. **Restore dependencies and build the project:**
   ```bash
   dotnet build
   ```
2. **Run the application:**
   ```bash
   dotnet run
   ```

## 📂 Folder Structure
* `Program.cs` - The main entry point of the application containing the source code.
* `*.csproj` - The C# project configuration file detailing the target .NET framework.

## 📝 What I Learned
* Setting up a local C# development environment.
* Working with basic terminal string outputs (`Console.WriteLine`).
* Understanding compiled vs. runtime processes in .NET.
